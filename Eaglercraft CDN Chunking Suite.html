Deployment & CDN Bypass Workflow Guide

jsDelivr enforces a strict hard limit of 20MB per file. Heavy HTML single-file builds (like Eaglercraft WebGL clients containing embedded assets) exceed this cap. By splitting the main HTML string across multiple sub-files and using an SVG dynamic loader, you completely bypass this limit.

1

Split HTML Client

Upload your single `.html` Eaglercraft client into the Splitter tab. Set chunk size to ~15MB. Click process to get `part1.html`, `part2.html`, etc., and `index.svg`.

2

Push to GitHub

Commit and push all generated `part*.html` files along with `index.svg` into your target GitHub repository branch.

3

Access via CDN URL

Direct users or embeds to your jsDelivr SVG URL. The SVG will automatically download all chunks asynchronously, stitch them, and boot Eaglercraft instantly.
